# tinitiate_com

TINITIATE's Next.js website for enterprise services and solo entrepreneur or small business services.

## Routes
- `/` - Home
- `/about`
- `/contact`
- `/case-studies`
- `/enterprise-services`
- `/solo-entrepreneur-services`
- `/request-callback`

## Run it
```
npm install
npm run dev
```
Open http://localhost:3000

## Build for production
```
npm run build
npm start
```

## Netlify Forms
The `tinitiate-com-callback` form posts to Netlify Forms. Its static detection blueprint is in `public/__forms.html`. Configure the form submission email recipient in the Netlify project notifications.
